### API contract (mock — required)

Implement Route Handlers:

**`GET /api/vacantes`** → JSON array:

```json
{
  "id": "uuid",
  "titulo": "Ingeniero Full-stack Senior (Next.js & Go)",
  "descripcion": "...",
  "ubicacion": "San Salvador",
  "tipoContrato": "Remoto",
  "salarioMin": 3500,
  "salarioMax": 5200,
  "estaActiva": true,
  "screeningActivo": true,
  "umbralPuntaje": 60,
  "createdAt": "2026-06-01T10:00:00Z",
  "updatedAt": "2026-06-01T10:00:00Z",
  "requisitos": ["React", "Next.js", "Go"],
  "postulacionesCount": 12
}
```

Seed **at least 12** realistic vacancies (use titles from Figma cards: Full-stack, Ciberseguridad, UI/UX, DBA, Mobile Kotlin, Data Scientist, DevOps, QA, AI Lead, etc.).

Client fetch:

```ts
const res = await fetch('/api/vacantes');
const vacantes: VacanteDTO[] = await res.json();
```

Map to UI with a `mapVacante()` helper:

```ts
function mapVacante(v: VacanteDTO) {
  return {
    id: v.id,
    title: v.titulo,
    location: v.ubicacion,
    type: v.tipoContrato,
    salary: formatSalary(v.salarioMin, v.salarioMax),
    isNew: isWithinDays(v.createdAt, 2),
    requirements: v.requisitos,
    description: v.descripcion,
  };
}
```

**Never** use `job.title` in API layer — only `titulo` in JSON.

### Responsive rules (mandatory)

Follow these — they prevent the white bar on the right:

1. **One layout breakpoint: `768px`** (hero 2-col vs stack; search row vs column).
2. **No** `max-width: 1280px` on `body`. Inner content: `max-w-[min(90vw,1600px)] mx-auto px-[clamp(12px,4vw,32px)]`.
3. **No** fixed pixel `left-[747px]` or card positions. CSS Grid / Flex only.
4. Job grid: `repeat(auto-fit, minmax(min(100%, 280px), 1fr))`.
5. Flex children: `min-w-0` on inputs in search row.
6. `html, body { overflow-x: clip; max-width: 100%; }`.
7. Filter chips: `overflow-x-auto` on mobile, single row.
8. Typography: hero `clamp(1.75rem, 5vw + 1rem, 4.5rem)`; body max 16px.
